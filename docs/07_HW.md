## 1. Mikroinformatika eta Sentsorizazioa - IoT (IE1)
*Rubrika Aurreratua (10):* 4 sentsore edo gehiagotik datuak jaso, eta hari gabeko **bi komunikazio mota** erabili datuak zerbitzarira bidaltzeko (WiFi eta Bluetooth).

### 1.1. Hardware Plataforma eta Sentsoreen Zerrenda
* **Plataforma:** ESP32 / Arduino / Raspberry Pi Pico W.
* **Konektatutako Sentsoreak (gutxienez 4):**
  1. **Tenperatura eta Hezetasuna:** DHT22 / BME280 sentsorea.
  2. **Argi-intentsitatea:** LDR (Fotoerresistentzia) edo BH1750.
  3. **Mugimendua (Presentzia):** PIR HC-SR501 sentsorea.
  4. **Gasa / Airearen Kalitatea:** MQ-135 / MQ-2 sentsorea.
  5. *(Aukerakoa)* **Soinu sentsorea:** Mikrofono modulua (KY-038).

### 1.2. Hari Gabeko Komunikazioak: WiFi eta Bluetooth (BLE)
* **WiFi Bidezko Bidalketa:** HTTP POST / MQTT bidez zerbitzariaren APIra (`/api/sentsoreak.php`).
* **Bluetooth (BLE) Bidezko Bidalketa:** BLE GATT zerbitzua datuak inguruko terminal edo pasabidera (Gateway) igortzeko.
* **Ebidentziak:**
> *(Gehitu hemen muntaketa fisikoaren argazkia, kontsolako datuak eta WiFi/Bluetooth konexioen frogak)*

## 2. Biltegiratze Segurua eta Babes Kopiak (IE3)

### 2.1. Hardware RAID 5+ eta Sareko NAS Sistema
*Rubrika Aurreratua (10):* RAID 5 edo hobea muntatu, sarean irisgarri NAS moduan sistema eragile propioarekin (TrueNAS CORE / OpenMediaVault).

* **RAID Mota:** RAID 5 (Gutxienez 3 disko, paritate banatua eta disko baten hutsegitearen aurkako babesa).
* **NAS Sistema Eragilea:** TrueNAS CORE / OpenMediaVault instalatuta ordenagailu dedikatu batean.
* **Sareko Partekaketa:** SMB / NFS protokoloak baimenekin konfiguratuta barne sareko erabiltzaileentzat.
* **Ebidentziak:**
> *(Gehitu hemen diskoen konfigurazioa, RAIDaren egoera "HEALTHY" eta SMB sarbidearen argazkiak)*

### 2.2. Zerbitzariaren Babes Kopien Plana eta Software Librea
*Rubrika Aurreratua (10):* Babes kopien plan osoa eta software libre bidezko inplementazio aurreratua (BorgBackup / Duplicati / Restic).

* **Babes Kopien Politika (3-2-1 Araua):**
  - 3 kopia datu kritiko guztietatik.
  - 2 euskarri ezberdinetan (RAID NAS lokala + kanpoko diskoa / bigarren zerbitzaria).
  - 1 kopia gunetik kanpo (Remote / Off-site).
* **Kopia Motak eta Maiztasuna:**
  - Egunero: Kopia gehigarria (Inkrementala edo diferentziala).
  - Astero: Kopia osoa (Full backup).
* **Erabilitako Software Librea:** Duplicati (zifratze sendoarekin AES-256) edo BorgBackup.
* **Ebidentziak:**
> *(Gehitu hemen softwarearen interfazea, atazen programazioa eta leheneratze arrakastatsuaren proba)*

## 3. Zentroetako Hardware Espezifikoa eta Inbentarioa (IE4)

### 3.1. Hardware eta Software Inbentario Automatikoa (GLPI + Agentea)
*Rubrika Aurreratua (10):* Sare bidezko inbentario automatikoa urrunetik, astero automatikoki exekutatzen dena.

* **Tresna:** GLPI + GLPI Agent / FusionInventory.
* **Arkitektura:**
  - GLPI zerbitzaria sarean hedatuta.
  - Agenteak bezero eta zerbitzarietan instalatuta (Windows zerbitzariak, Linux nodoak, bezero-ekipoak).
* **Programazio Automatikoa:**
  - Windows Task Scheduler / Linux Cron bidez: agentea astero behin automatikoki exekutatzen da eta GLPI zerbitzarian hardware/software aldaketak eguneratzen ditu.
```bash
# Linux proba:
glpi-agent --force
```
* **Ebidentziak:**
> *(Gehitu hemen GLPI-n agertzen den ekipoen hardware zerrenda eta automatikoki sortutako txostenak)*
